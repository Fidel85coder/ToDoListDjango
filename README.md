# 📝 Task Management App (Django)

A web-based task management application built with **Django** that enables users to organize and track their daily tasks. Each user can create an account to manage, search, and update their personal tasks with data isolation across accounts.

---

## 🚀 Features

- **User Authentication:** Account registration, secure login, and session management.
- **Full CRUD Operations:**
  - Create tasks with titles and optional descriptions.
  - Edit existing tasks and toggle completion status.
  - Delete completed or unwanted tasks.
  - View individual task details.
- **Real-Time Search & Filtering:** Filter tasks by title dynamically via a search bar.
- **Pending Task Counter:** Live indicator showing remaining incomplete tasks.
- **Data Isolation:** Ensures authenticated users can only view and modify their own tasks.

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Web Framework:** Django (Class-Based Views)
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3 / Django Templates
- **Version Control:** Git & GitHub
